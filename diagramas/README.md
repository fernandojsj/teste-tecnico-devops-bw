# Diagramas

Diagramas de arquitetura e fluxo que ilustram as respostas, principalmente do bloco 4 (esteira CI/CD).

Os diagramas são feitos no draw.io. Cada um fica com dois arquivos: o fonte editável (`.drawio`) e uma imagem exportada (`.png`), pra dar pra visualizar direto no GitHub sem precisar abrir o draw.io.
